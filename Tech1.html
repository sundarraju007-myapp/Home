📖 ஒரு Real-Time Story

Network concepts-ஐ ஒரு நகரத்தின் கதையாக புரிந்துகொள்வோம்.

🌆 "சுந்தர்ராஜுவின் Smart City"

ஒரு நாள் சுந்தர்ராஜு ஒரு Smart City-க்கு செல்கிறார். அவருடைய கையில் ஒரு smartphone. சாலையில் connected cars. மருத்துவமனையில் wireless sensors. நகரம் முழுவதும் wireless communication devices.

அப்போது ஒரு கார் மற்றொரு காருக்கு "முன்னால் accident!" என்று message அனுப்புகிறது. இது VANET.

அதே நேரத்தில் சாலையில் infrastructure இல்லாவிட்டாலும் பல mobile devices ஒன்றுக்கொன்று தகவல் அனுப்புகின்றன. இது MANET.

மருத்துவமனையில் heartbeat, temperature போன்ற தகவல்களை சிறிய sensors சேகரித்து gateway-க்கு அனுப்புகின்றன. இது WSN.

Wireless spectrum குறைவாக இருக்கும்போது, unused spectrum-ஐ intelligent முறையில் பயன்படுத்தும் technology CRN.

அந்த smartphone 2G-ல் தொடங்கி 3G, 4G, பின்னர் 5G network-ஐ பயன்படுத்துகிறது. இதுவே wireless communication-ன் evolution.

இந்த முழு network-ஐ computer-ல் experiment செய்ய NS-2 / NS-3 simulation tools பயன்படுத்தலாம்.

📚 முக்கியமான Topics

ஒவ்வொரு technology-யையும் practical example மூலம் கற்றுக்கொள்ளுங்கள்.

📱

MANET

Mobile Ad Hoc Network

Fixed infrastructure இல்லாமல் mobile nodes தங்களுக்குள் communication செய்யும் network.

Example: Disaster area emergency communication.

🚗

VANET

Vehicular Network

Vehicles ஒன்றுக்கொன்று மற்றும் roadside infrastructure-உடன் communication செய்வது.

Example: Accident warning.

🌡️

WSN

Wireless Sensor Network

பல sensor nodes environmental அல்லது physical information collect செய்து gateway/base station-க்கு அனுப்பும்.

Example: Temperature monitoring.

📡

CRN

Cognitive Radio Network

Spectrum availability-ஐ உணர்ந்து available spectrum-ஐ பயன்படுத்தும் intelligent wireless network.

Example: Dynamic spectrum access.

📶

Wireless Communication

Physical cable இல்லாமல் radio, microwave போன்ற electromagnetic communication மூலம் தகவல் பரிமாற்றம்.

💻

Network Simulation

Real hardware இல்லாமல் network protocols, routing, packet delivery போன்றவற்றை simulation செய்வது.

💻 NS-2 & NS-3 Tutorial

Network simulation-ன் அடிப்படைகள்.

NS-2 என்றால்?

NS-2 என்பது network research மற்றும் education-ல் பயன்படுத்தப்பட்ட discrete-event network simulator.

Common workflow:

  1. Topology உருவாக்குதல்
  2. Nodes உருவாக்குதல்
  3. Links அமைத்தல்
  4. Traffic உருவாக்குதல்
  5. Simulation run செய்தல்
  6. Trace analysis

NS-3 என்றால்?

NS-3 என்பது network research, education மற்றும் protocol experimentation-க்கு பயன்படும் modern discrete-event network simulator.

C++ மற்றும் Python API-களைப் பயன்படுத்தி network models உருவாக்கலாம்.

📝 Basic NS-3 Concept

#include "ns3/core-module.h"
#include "ns3/network-module.h"
#include "ns3/internet-module.h"

using namespace ns3;

int main()
{
    NodeContainer nodes;

    // Create two nodes
    nodes.Create(2);

    InternetStackHelper internet;
    internet.Install(nodes);

    Simulator::Run();
    Simulator::Destroy();

    return 0;
}

🔬 Simulation Learning Flow

01 — Create Nodes

Network-ல் communication devices / nodes உருவாக்கவும்.

02 — Configure Network

Channels, devices, IP addresses போன்றவற்றை configure செய்யவும்.

03 — Install Applications

Traffic source மற்றும் destination applications அமைக்கவும்.

04 — Run Simulation

Simulator-ஐ இயக்கி packets travel செய்வதை observe செய்யவும்.

05 — Analyze Results

Throughput, delay, packet loss, PDR போன்ற metrics-ஐ ஆய்வு செய்யவும்.

❌ Packet Loss
