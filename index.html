⌨️ Tanglish → தமிழ்
English keyboard-ல் Tanglish-ஆக type செய்யலாம். Space அல்லது punctuation கொடுக்கும்போது தமிழ் வார்த்தையாக மாற்றப்படும்.

vanakkam → வணக்கம்
en peyar arun → என் பெயர் அருண்
html endral enna → HTML என்றால் என்ன
css etharku payanpadugirathu → CSS எதற்குப் பயன்படுகிறது
javascript enraal enna → JavaScript என்றால் என்ன
