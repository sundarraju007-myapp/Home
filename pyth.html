🐍 Python Fundamentals

Python அடிப்படைகள்

Python என்றால் என்ன?

Python என்பது high-level, general-purpose programming language. Readable syntax மற்றும் extensive libraries காரணமாக web development, automation, data science, AI/ML, scripting போன்ற பல துறைகளில் பயன்படுத்தப்படுகிறது.

Reusable Python code

Normal Function

def total(*numbers):

    return sum(numbers)

**kwargs

🧱 Object Oriented Programming

Python OOP Complete Notes

Class

Object உருவாக்க பயன்படும் blueprint.

Object

Class-ன் instance object எனப்படும்.

Inheritance

Parent class properties மற்றும் methods-ஐ child class பெறுதல்.

Polymorphism

ஒரே interface வெவ்வேறு behavior வழங்குதல்.

Encapsulation

Data மற்றும் methods-ஐ class-ல் bundle செய்தல்.

Abstraction

Implementation details மறைத்து essential interface வழங்குதல்.

Complete OOP Example

class Employee:

    company = "Sundarraju Tech"

    def __init__(self, name, salary):

        self.name = name
        self.salary = salary

    def display(self):

        print("Name:", self.name)
        print("Salary:", self.salary)


class Developer(Employee):

    def code(self):

        print(self.name, "is coding")


dev = Developer(
    "Sundarraju",
    75000
)

dev.display()
dev.code()

🚀 Advanced Python

Experienced Developer level concepts

🔄 Iterator

__iter__ மற்றும் __next__ protocol மூலம் sequential values வழங்கும் object.

⚡ Generator

yield மூலம் values-ஐ lazy evaluation முறையில் generate செய்யும் function.

🎨 Decorator

Existing function behavior-ஐ modify அல்லது extend செய்ய பயன்படும்.

🔒 Closure

Inner function enclosing scope variables-ஐ remember செய்வது.

🧹 Context Manager

Resource setup மற்றும் cleanup manage செய்ய with statement பயன்படும்.

⚡ Async/Await

I/O-bound asynchronous applications உருவாக்க பயன்படும்.

Generator Example

def numbers():

    for i in range(5):

        yield i


for number in numbers():

    print(number)

Decorator Example

def logger(func):

    def wrapper():

        print("Function started")

        func()

        print("Function ended")

    return wrapper


@logger
def hello():

    print("Hello Python")


hello()

🗄️ Python + Database

Database fundamentals

SQLite Example

import sqlite3

connection = sqlite3.connect(
    "students.db"
)

cursor = connection.cursor()

cursor.execute("""
CREATE TABLE IF NOT EXISTS students(
    id INTEGER PRIMARY KEY,
    name TEXT,
    mark INTEGER
)
""")

cursor.execute(
    "INSERT INTO students(name, mark) VALUES (?, ?)",
    ("Sundarraju", 95)
)

connection.commit()

connection.close()
⚠️ Security: SQL queries உருவாக்கும்போது user input-ஐ string concatenation மூலம் சேர்ப்பதை தவிர்த்து parameterized queries பயன்படுத்துவது முக்கியம்.

💻 Python Coding Programs

Interview coding practice

1. Reverse String

text = "python"

reverse = text[::-1]

print(reverse)

2. Palindrome

text = "madam"

if text == text[::-1]:
    print("Palindrome")
else:
    print("Not Palindrome")

3. Factorial

def factorial(n):

    if n == 0:
        return 1

    return n * factorial(n-1)


print(factorial(5))

4. Prime Number

n = 29

is_prime = True

for i in range(2, int(n ** .5) + 1):

    if n % i == 0:

        is_prime = False
        break

print(is_prime)

5. Fibonacci

a = 0
b = 1

for i in range(10):

    print(a)

    a, b = b, a + b

6. Duplicate Elements

numbers = [1,2,3,2,4,1]

duplicates = []

for x in numbers:

    if numbers.count(x) > 1 and x not in duplicates:

        duplicates.append(x)

print(duplicates)
