1. SQL என்றால் என்ன?

SQL என்பது Structured Query Language என்பதன் சுருக்கமாகும். Relational Database-ல் Data-வை உருவாக்க, சேமிக்க, தேட, மாற்ற மற்றும் நீக்க SQL பயன்படுத்தப்படுகிறது.

எளிய SQL Example


SELECT *
FROM employees;

இந்த Query employees table-ல் உள்ள அனைத்து columns மற்றும் rows-ஐ காட்டும்.

2. DDL — Data Definition Language

Database structure-ஐ உருவாக்கவும் மாற்றவும் DDL commands பயன்படுத்தப்படுகின்றன.

Command பயன்

ALTER Database object-ஐ மாற்றுதல்
DROP Object-ஐ நீக்குதல்
TRUNCATE Table-ல் உள்ள அனைத்து rows-ஐ நீக்குதல்

7. SQL Joins

இரண்டு அல்லது அதற்கு மேற்பட்ட tables-ல் உள்ள தொடர்புடைய data-வை இணைக்க JOIN பயன்படுத்தப்படுகிறது.

INNER JOIN


SELECT e.name, d.department_name
FROM employees e
INNER JOIN departments d
ON e.department_id = d.department_id;

LEFT JOIN


SELECT e.name, d.department_name
FROM employees e
LEFT JOIN departments d
ON e.department_id = d.department_id;

RIGHT JOIN


SELECT e.name, d.department_name
FROM employees e
RIGHT JOIN departments d
ON e.department_id = d.department_id;

FULL OUTER JOIN


SELECT e.name, d.department_name
FROM employees e
FULL OUTER JOIN departments d
ON e.department_id = d.department_id;

CROSS JOIN


SELECT *
FROM employees
CROSS JOIN departments;

SELF JOIN


SELECT
    e.name AS employee,
    m.name AS manager
FROM employees e
JOIN employees m
ON e.manager_id = m.employee_id;

8. Constraints

Constraint பயன்
PRIMARY KEY ஒவ்வொரு row-ஐ தனித்துவமாக அடையாளம் காணும்
FOREIGN KEY மற்றொரு table-ஐ reference செய்யும்
UNIQUE Duplicate values-ஐ கட்டுப்படுத்தும்
NOT NULL NULL value-ஐ அனுமதிக்காது
CHECK ஒரு condition-ஐ enforce செய்யும்
DEFAULT Default value வழங்கும் 

CREATE TABLE employees (
    id INT PRIMARY KEY,

    email VARCHAR(150) UNIQUE,

    salary DECIMAL(10,2)
        CHECK (salary >= 0),

    country VARCHAR(50)
        DEFAULT 'India'
);

10. Advanced SQL

CASE


SELECT
    name,
    salary,

    CASE
        WHEN salary >= 100000
            THEN 'High'

        WHEN salary >= 50000
            THEN 'Medium'

        ELSE 'Low'
    END AS salary_level

FROM employees;

CTE


WITH high_salary AS
(
    SELECT *
    FROM employees
    WHERE salary > 100000
)

SELECT *
FROM high_salary;

ROW_NUMBER


SELECT
    name,
    department,
    salary,

    ROW_NUMBER() OVER(
        PARTITION BY department
        ORDER BY salary DESC
    ) AS row_num

FROM employees;

RANK


SELECT
    name,
    salary,

    RANK() OVER(
        ORDER BY salary DESC
    ) AS salary_rank

FROM employees;

LAG


SELECT
    employee_id,
    salary,

    LAG(salary) OVER(
        ORDER BY employee_id
    ) AS previous_salary

FROM employees;

12. Normalization

  • 1NF: Atomic values மற்றும் repeating groups இல்லாமல் அமைத்தல்.
  • 2NF: 1NF + partial dependency இல்லாமல் அமைத்தல்.
  • 3NF: 2NF + transitive dependency இல்லாமல் அமைத்தல்.
  • BCNF: 3NF-ஐ விட வலுவான normalization வடிவம்.

14. 100 முக்கியமான SQL Interview Questions & Answers

1. SQL என்றால் என்ன?
SQL என்பது relational database-ல் data-வை query மற்றும் manipulate செய்யப் பயன்படும் language.
2. Database என்றால் என்ன?
Database என்பது ஒழுங்குபடுத்தப்பட்ட data-வின் தொகுப்பு.
3. DBMS என்றால் என்ன?
Database-ஐ உருவாக்கவும் நிர்வகிக்கவும் பயன்படும் software DBMS ஆகும்.
4. RDBMS என்றால் என்ன?
Tables மற்றும் அவற்றுக்கிடையிலான relationships அடிப்படையில் data-வை நிர்வகிக்கும் DBMS relational DBMS ஆகும்.
5. Table என்றால் என்ன?
Rows மற்றும் columns கொண்ட database object table ஆகும்.
6. Primary Key என்றால் என்ன?
ஒரு table-ல் ஒவ்வொரு row-ஐ unique-ஆக identify செய்யும் key primary key ஆகும்.
7. Foreign Key என்றால் என்ன?
மற்றொரு table-ன் key-ஐ reference செய்யும் column அல்லது columns foreign key ஆகும்.
8. UNIQUE constraint என்றால் என்ன?
ஒரே value மீண்டும் வராமல் கட்டுப்படுத்த UNIQUE constraint பயன்படுகிறது.
9. NOT NULL என்றால் என்ன?
ஒரு column-ல் NULL value இருக்கக்கூடாது என்பதை NOT NULL குறிப்பிடுகிறது.
10. CHECK constraint என்றால் என்ன?
ஒரு குறிப்பிட்ட condition-ஐ column values பின்பற்ற CHECK constraint பயன்படுகிறது.
11. DEFAULT என்றால் என்ன?
INSERT செய்யும்போது value வழங்கப்படாவிட்டால் பயன்படுத்தப்படும் default value.
12. DDL என்றால் என்ன?
Data Definition Language. CREATE, ALTER, DROP போன்ற commands இதில் அடங்கும்.
13. DML என்றால் என்ன?
Data Manipulation Language. INSERT, UPDATE, DELETE போன்ற data manipulation commands இதில் அடங்கும்.
14. SELECT என்றால் என்ன?
Database-ல் இருந்து data-வை retrieve செய்ய SELECT பயன்படுகிறது.
15. WHERE என்றால் என்ன?
குறிப்பிட்ட condition அடிப்படையில் rows-ஐ filter செய்ய WHERE பயன்படுகிறது.
16. GROUP BY என்றால் என்ன?
ஒத்த values கொண்ட rows-ஐ groups-ஆக பிரித்து aggregate calculation செய்ய GROUP BY பயன்படுகிறது.
17. HAVING என்றால் என்ன?
GROUP BY மூலம் உருவாக்கப்பட்ட groups-ஐ filter செய்ய HAVING பயன்படுகிறது.
18. WHERE மற்றும் HAVING வித்தியாசம்?
WHERE rows-ஐ filter செய்கிறது; HAVING groups அல்லது aggregate results-ஐ filter செய்கிறது.
19. ORDER BY என்றால் என்ன?
Query result-ஐ ascending அல்லது descending order-ல் sort செய்ய ORDER BY பயன்படுகிறது.
20. DISTINCT என்றால் என்ன?
Duplicate result rows-ஐ நீக்க DISTINCT பயன்படுகிறது.
21. INNER JOIN என்றால் என்ன?
இரண்டு tables-லும் matching rows மட்டும் INNER JOIN மூலம் கிடைக்கும்.
22. LEFT JOIN என்றால் என்ன?
Left table-ன் அனைத்து rows மற்றும் matching right table rows கிடைக்கும்.
23. RIGHT JOIN என்றால் என்ன?
Right table-ன் அனைத்து rows மற்றும் matching left table rows கிடைக்கும்.
24. FULL OUTER JOIN என்றால் என்ன?
இரு tables-ல் matching மற்றும் unmatched rows இரண்டையும் பெற FULL OUTER JOIN பயன்படுகிறது.
25. CROSS JOIN என்றால் என்ன?
இரண்டு tables-ன் அனைத்து possible row combinations-ஐ CROSS JOIN உருவாக்கும்.
26. SELF JOIN என்றால் என்ன?
ஒரே table-ஐ இரண்டு aliases மூலம் அதே table-உடன் join செய்வது SELF JOIN.
27. Subquery என்றால் என்ன?
ஒரு SQL query-க்குள் இருக்கும் மற்றொரு query subquery எனப்படும்.
28. Correlated Subquery என்றால் என்ன?
Outer query-ன் values-ஐ reference செய்யும் subquery correlated subquery ஆகும்.
29. CTE என்றால் என்ன?
WITH keyword மூலம் உருவாக்கப்படும் named temporary query result CTE ஆகும்.
30. Recursive CTE என்றால் என்ன?
தன்னைத்தானே reference செய்யும் CTE recursive CTE ஆகும்.
31. View என்றால் என்ன?
Stored SELECT query-ஐ table போல பயன்படுத்துவது View.
32. Index என்றால் என்ன?
சில queries-ன் data access-ஐ வேகப்படுத்த database பயன்படுத்தும் data structure Index.
33. Composite Index என்றால் என்ன?
இரண்டு அல்லது அதற்கு மேற்பட்ட columns-ஐ கொண்ட index Composite Index.
34. Normalization என்றால் என்ன?
Data redundancy மற்றும் undesirable dependencies-ஐ குறைக்க database structure-ஐ ஒழுங்குபடுத்துவது normalization.
35. Denormalization என்றால் என்ன?
Performance அல்லது reporting தேவைக்காக திட்டமிட்டு சில redundancy-ஐ சேர்ப்பது denormalization.
36. 1NF என்றால் என்ன?
Atomic values மற்றும் repeating groups இல்லாத table structure 1NF-ன் அடிப்படை கருத்து.
37. 2NF என்றால் என்ன?
1NF மற்றும் composite key-ன் ஒரு பகுதியை மட்டும் சார்ந்த partial dependency இல்லாத நிலை 2NF.
38. 3NF என்றால் என்ன?
Transitive dependency-ஐ தவிர்க்கும் normalization நிலை 3NF.
39. ACID என்றால் என்ன?
Atomicity, Consistency, Isolation, Durability என்பவை ACID properties.
40. Transaction என்றால் என்ன?
ஒரு logical unit of database work transaction எனப்படும்.
41. COMMIT என்றால் என்ன?
Transaction changes-ஐ commit செய்ய COMMIT பயன்படுகிறது.
42. ROLLBACK என்றால் என்ன?
Rollback செய்யக்கூடிய transaction changes-ஐ undo செய்ய ROLLBACK பயன்படுகிறது.
43. Deadlock என்றால் என்ன?
Transactions ஒன்றுக்கொன்று வைத்திருக்கும் resources-க்காக காத்திருக்கும் cycle உருவானால் deadlock ஏற்படலாம்.
44. Window Function என்றால் என்ன?
Individual rows-ஐ collapse செய்யாமல் related rows மீது calculation செய்ய window functions பயன்படுகின்றன.
45. ROW_NUMBER என்றால் என்ன?
ஒவ்வொரு row-க்கும் sequential unique number வழங்க ROW_NUMBER பயன்படுகிறது.
46. RANK என்றால் என்ன?
Tie ஏற்பட்டால் ஒரே rank வழங்கி அடுத்த rank-ல் gap விடும் function RANK.
47. DENSE_RANK என்றால் என்ன?
Tie-க்கு ஒரே rank வழங்கும்; ஆனால் அடுத்த rank-ல் gap இருக்காது.
48. PARTITION BY என்றால் என்ன?
Window function calculation-க்காக rows-ஐ logical groups-ஆக பிரிக்க PARTITION BY பயன்படுகிறது.
49. LAG என்றால் என்ன?
Previous row-ன் value-ஐ பெற LAG பயன்படுகிறது.
50. LEAD என்றால் என்ன?
Next row-ன் value-ஐ பெற LEAD பயன்படுகிறது.
51. COALESCE என்றால் என்ன?
கொடுக்கப்பட்ட expressions-ல் முதல் non-NULL value-ஐ COALESCE return செய்கிறது.
52. NULL என்றால் என்ன?
NULL என்பது unknown, missing அல்லது inapplicable value-ஐ குறிக்கிறது.
53. NULL-ஐ எப்படி check செய்வது?
IS NULL அல்லது IS NOT NULL பயன்படுத்த வேண்டும். = NULL பயன்படுத்தக்கூடாது.
54. CASE என்றால் என்ன?
SQL-ல் conditional logic உருவாக்க CASE பயன்படுகிறது.
55. UNION என்றால் என்ன?
Compatible result sets-ஐ combine செய்து duplicate rows-ஐ remove செய்ய UNION பயன்படுகிறது.
56. UNION மற்றும் UNION ALL வித்தியாசம்?
UNION duplicates-ஐ remove செய்யும்; UNION ALL duplicates-ஐ retain செய்யும்.
57. EXISTS என்றால் என்ன?
Subquery குறைந்தது ஒரு row return செய்கிறதா என்பதை EXISTS check செய்கிறது.
58. EXISTS மற்றும் IN வித்தியாசம்?
இவை membership/existence logic-ஐ வெவ்வேறு விதமாக express செய்கின்றன; performance database மற்றும் query-ஐ பொறுத்தது.
59. Stored Procedure என்றால் என்ன?
Database-ல் store செய்யப்பட்ட executable program logic Stored Procedure.
60. Trigger என்றால் என்ன?
குறிப்பிட்ட database event ஏற்பட்டவுடன் தானாக execute ஆகும் database logic Trigger.
61. Schema என்றால் என்ன?
Database objects-க்கான logical namespace அல்லது container Schema.
62. Candidate Key என்றால் என்ன?
Rows-ஐ uniquely identify செய்யும் minimal attribute set Candidate Key.
63. Surrogate Key என்றால் என்ன?
Business meaning இல்லாத artificial identifier Surrogate Key.
64. Natural Key என்றால் என்ன?
Real-world meaningful attribute-ஐ key ஆக பயன்படுத்துவது Natural Key.
65. Referential Integrity என்றால் என்ன?
Foreign key relationships valid-ஆக இருப்பதை உறுதி செய்வது Referential Integrity.
66. CASCADE DELETE என்றால் என்ன?
Parent row delete செய்யும்போது தொடர்புடைய child rows-ஐ database automatically delete செய்ய ON DELETE CASCADE பயன்படலாம்.
67. Cartesian Product என்றால் என்ன?
இரண்டு datasets-ன் அனைத்து possible row combinations Cartesian Product.
68. Alias என்றால் என்ன?
Query-க்குள் table அல்லது expression-க்கு temporary name கொடுப்பது Alias.
69. COUNT(DISTINCT column) என்றால் என்ன?
ஒரு expression-ன் distinct non-NULL values-ஐ count செய்ய இது பயன்படும்.
70. Duplicate values-ஐ எப்படி கண்டுபிடிப்பது?
GROUP BY மற்றும் HAVING COUNT(*) > 1 பயன்படுத்தலாம்.
71. Second Highest Salary எப்படி கண்டுபிடிப்பது?
MAX(salary)-ஐ விட குறைவான salaries-ல் MAX எடுப்பது ஒரு வழி. DENSE_RANK போன்ற window functions-ஐயும் பயன்படுத்தலாம்.
72. Average Salary-ஐ விட அதிகம் பெறுபவர்களை எப்படி கண்டுபிடிப்பது?
Salary-ஐ SELECT AVG(salary) FROM employees என்ற subquery-உடன் compare செய்யலாம்.
73. Query Optimization என்றால் என்ன?
Query-ஐ execute செய்ய database engine efficient execution strategy தேர்வு செய்வது Query Optimization.
74. Execution Plan என்றால் என்ன?
ஒரு SQL query எப்படி execute செய்யப்படும் என்பதை database engine திட்டமிடும் representation Execution Plan.
75. Index ஏன் INSERT/UPDATE-ஐ slow செய்யலாம்?
Indexed data மாற்றப்படும்போது indexes-ஐயும் maintain செய்ய வேண்டியதால் additional work ஏற்படும்.
76. Covering Index என்றால் என்ன?
Query-க்கு தேவையான தகவல்கள் index-லேயே போதுமானதாக இருந்தால் base table access குறையலாம்.
77. Clustered Index என்றால் என்ன?
Table data storage organization index key-ஐ அடிப்படையாகக் கொண்ட அமைப்பு clustered indexing எனப்படும்; implementation DBMS-ஐ பொறுத்தது.
78. Non-Clustered Index என்றால் என்ன?
Table data storage-இலிருந்து தனியாக இருக்கும் index structure non-clustered index எனப்படும்.
79. Isolation Level என்றால் என்ன?
Concurrent transactions ஒன்றுக்கொன்று எவ்வாறு தெரியும் என்பதை transaction isolation level கட்டுப்படுத்துகிறது.
80. Dirty Read என்றால் என்ன?
மற்றொரு transaction commit செய்யாத data-வை read செய்வது Dirty Read.
81. Non-Repeatable Read என்றால் என்ன?
ஒரே transaction-ல் ஒரே row-ஐ இரண்டு முறை படிக்கும்போது வேறுபட்ட committed values கிடைப்பது.
82. Phantom Read என்றால் என்ன?
ஒரே range query-ஐ மீண்டும் execute செய்யும்போது புதிய அல்லது நீக்கப்பட்ட qualifying rows காரணமாக result set மாறுவது.
83. SQL Injection என்றால் என்ன?
Untrusted input மூலம் SQL statement-ன் intended meaning மாற்றப்படும் attack SQL Injection.
84. SQL Injection-ஐ எப்படி prevent செய்வது?
Parameterized queries அல்லது prepared statements பயன்படுத்துவது முக்கியமான பாதுகாப்பு நடைமுறை.
85. Prepared Statement என்றால் என்ன?
SQL structure மற்றும் parameter values-ஐ தனித்தனியாக handle செய்யும் mechanism Prepared Statement.
86. DELETE மற்றும் TRUNCATE வித்தியாசம்?
DELETE குறிப்பிட்ட rows-ஐ WHERE மூலம் remove செய்யலாம்; TRUNCATE table-ல் உள்ள அனைத்து rows-ஐ DBMS-specific semantics மூலம் remove செய்கிறது.
87. DROP மற்றும் TRUNCATE வித்தியாசம்?
DROP database object-ஐ remove செய்கிறது; TRUNCATE table structure-ஐ வைத்துக்கொண்டு rows-ஐ remove செய்கிறது.
88. NULLIF என்றால் என்ன?
இரண்டு expressions equal என்றால் NULL return செய்யும் function NULLIF.
89. Aggregate Function என்றால் என்ன?
பல rows-லிருந்து ஒரு calculation result உருவாக்கும் function Aggregate Function.
90. Scalar Function என்றால் என்ன?
ஒரு input அல்லது row expression-க்கு ஒரு single value return செய்யும் function.
91. SQL Pagination என்றால் என்ன?
பெரிய result set-ஐ சிறிய பகுதிகளாக retrieve செய்வது Pagination.
92. Upsert என்றால் என்ன?
Row இல்லையெனில் INSERT மற்றும் இருந்தால் UPDATE செய்வது Upsert.
93. MERGE என்றால் என்ன?
Conditional INSERT/UPDATE போன்ற operations-ஐ ஒரே statement மூலம் செய்ய சில DBMS-களில் MERGE பயன்படுகிறது.
94. Materialized View என்றால் என்ன?
Query result-ஐ physically store செய்யும் view Materialized View.
95. Partitioning என்றால் என்ன?
பெரிய table அல்லது index-ஐ smaller partitions-ஆக பிரிப்பது Partitioning.
96. Horizontal Partitioning என்றால் என்ன?
Rows-ஐ partitions-ஆக பிரிப்பது Horizontal Partitioning.
97. Vertical Partitioning என்றால் என்ன?
Columns-ஐ வெவ்வேறு storage structures அல்லது tables-ஆக பிரிப்பது Vertical Partitioning.
98. SQL-ல் Second Highest Salary கண்டுபிடிக்க மற்றொரு வழி என்ன?
DENSE_RANK() OVER (ORDER BY salary DESC) பயன்படுத்தி rank = 2 உள்ள rows-ஐ தேர்வு செய்யலாம்.
99. SQL கற்க முக்கியமான topics என்ன?
SELECT, WHERE, JOIN, GROUP BY, HAVING, subqueries, CTE, window functions, transactions, indexes மற்றும் query optimization ஆகியவை முக்கியமான topics.
100. SQL கற்ற பிறகு என்ன practice செய்ய வேண்டும்?
Real-world tables உருவாக்கி JOIN, aggregation, subquery, CTE, window functions மற்றும் interview queries ஆகியவற்றை தொடர்ந்து practice செய்ய வேண்டும்.
