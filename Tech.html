🛡️ 2. Cybersecurity

Cybersecurity என்பது computers, networks, applications மற்றும் data ஆகியவற்றை cyber threats-இலிருந்து பாதுகாக்கும் நடைமுறைகள் மற்றும் technologies.

🔐 CIA Triad

  • Confidentiality: தகவலை authorized users மட்டும் அணுகுதல்.
  • Integrity: தகவல் unauthorized-ஆக மாற்றப்படாமல் பாதுகாத்தல்.
  • Availability: தேவையான நேரத்தில் system/data கிடைப்பதை உறுதி செய்தல்.

📖 Real-Time Story: Company Login Security

1 👤 Employee login செய்கிறார்.
2 🔐 Password verification நடைபெறுகிறது.
3 📱 MFA verification நடைபெறுகிறது.
4 🛡️ Access policy சரிபார்க்கப்படுகிறது.
5 ✅ Authorized user application-ஐ அணுகுகிறார்.

🔐 5. Cryptography

Cryptography என்பது information-ஐ பாதுகாப்பதற்காக mathematical algorithms மற்றும் keys பயன்படுத்தும் security discipline.
