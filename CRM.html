📚 What is Machine Learning?

Machine Learning (ML) is a branch of Artificial Intelligence where computers learn patterns from data and use those patterns to make predictions or decisions.

Data → Algorithm → Training → Model → Prediction

Basic ML Workflow

  1. Collect data
  2. Clean the data
  3. Explore the data
  4. Choose features
  5. Split training and testing data
  6. Choose an algorithm
  7. Train the model
  8. Evaluate the model
  9. Make predictions
  10. Improve the model

1. 🎯 Supervised Learning

Regression

Linear Regression

Used when the output is a continuous numerical value. Example: predicting house price from house size.

y = mx + b
  1. Collect input X and output Y.
  2. Plot the data.
  3. Find the best-fit line.
  4. Calculate prediction error.
  5. Adjust model parameters.
  6. Use the trained model for prediction.
Problem:
A house has 1000 sq.ft. and costs ₹50 lakh. Another has 2000 sq.ft. and costs ₹90 lakh. What type of ML problem is this?
Regression, because the target value is a continuous number: house price.
Classification

Logistic Regression

Used to classify data into categories such as Yes/No, Spam/Not Spam, Disease/No Disease.

P(y=1) = 1 / (1 + e-z)
  1. Prepare labelled training data.
  2. Calculate weighted input.
  3. Apply the sigmoid function.
  4. Convert probability into a class.
  5. Measure classification error.
  6. Update the parameters.
Classification / Regression

Decision Tree

A Decision Tree repeatedly asks questions about features and follows branches until it reaches a prediction.

  1. Select the best feature for splitting.
  2. Create a decision node.
  3. Split the dataset.
  4. Repeat for each branch.
  5. Stop when a suitable leaf is reached.
  6. Use the leaf value/class for prediction.
Ensemble

Random Forest

Random Forest combines many decision trees to produce a stronger prediction.

  1. Create multiple random samples of the training data.
  2. Build a decision tree for each sample.
  3. Randomly select features at each split.
  4. Train many trees.
  5. Combine their predictions.
Random Forest = Many Decision Trees + Aggregated Prediction
Classification

K-Nearest Neighbors — KNN

KNN predicts a data point using the classes of its nearest neighbours.

Distance = √((x₁-x₂)² + (y₁-y₂)²)
  1. Choose K.
  2. Calculate distance from the new point to training points.
  3. Find the K nearest points.
  4. Count their classes.
  5. Choose the majority class.
Classification

Support Vector Machine — SVM

SVM finds a decision boundary that separates classes while attempting to maximize the margin between them.

  1. Represent data as feature vectors.
  2. Search for a separating hyperplane.
  3. Maximize the margin.
  4. Use kernel functions when nonlinear separation is required.
Probabilistic

Naive Bayes

Naive Bayes uses Bayes' theorem and assumes conditional independence between features.

P(A|B) = P(B|A)P(A) / P(B)

Common application: email spam classification and text classification.

2. 🔍 Unsupervised Learning

K-Means Clustering

K-Means groups similar data points into K clusters.

  1. Choose the number of clusters K.
  2. Randomly initialize K centroids.
  3. Assign each point to its nearest centroid.
  4. Calculate new centroid positions.
  5. Repeat assignment and update steps.
  6. Stop when centroids stabilize.
Goal: Minimize the distance between points and their cluster centroid.

Hierarchical Clustering

Creates a hierarchy of clusters, often represented using a dendrogram.

  1. Start with every point as a separate cluster.
  2. Find the closest clusters.
  3. Merge them.
  4. Repeat until one hierarchy is created.
  5. Choose the desired level of clusters.

PCA — Principal Component Analysis

PCA reduces the number of dimensions while attempting to preserve important variation in the data.

  1. Standardize the features.
  2. Calculate the covariance structure.
  3. Find principal directions.
  4. Rank components by explained variance.
  5. Project the data onto selected components.

3. 🧠 Deep Learning

Artificial Neural Network — ANN

An ANN contains interconnected neurons organized into layers.

Input Layer → Hidden Layer(s) → Output Layer
  1. Initialize weights.
  2. Pass input through the network.
  3. Calculate output.
  4. Calculate loss.
  5. Backpropagate the error.
  6. Update weights.
  7. Repeat for multiple epochs.

CNN — Convolutional Neural Network

CNNs are particularly useful for image and spatial data.

  1. Input image.
  2. Apply convolution filters.
  3. Apply activation.
  4. Perform pooling.
  5. Extract important features.
  6. Classify using final layers.

RNN — Recurrent Neural Network

RNNs process sequential information by maintaining information from previous time steps.

Applications include sequence modelling, text and time-series problems.

Transformer

Transformers use attention mechanisms to model relationships between elements in sequences.

  1. Convert input into representations.
  2. Add positional information where required.
  3. Calculate attention.
  4. Combine contextual information.
  5. Pass through feed-forward layers.
  6. Repeat through transformer blocks.

4. 🎮 Reinforcement Learning

Q-Learning

An agent learns which actions are useful by interacting with an environment and receiving rewards.

Q(s,a) ← Q(s,a) + α[r + γ max Q(s',a') - Q(s,a)]
  1. Initialize Q values.
  2. Observe the current state.
  3. Choose an action.
  4. Receive a reward.
  5. Observe the next state.
  6. Update the Q value.
  7. Repeat until the policy improves.

Examples: games, robotics, resource allocation and sequential decision problems.
