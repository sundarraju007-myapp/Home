import pandas as pd

from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

data = pd.read_csv("dataset.csv")

X = data.drop("target", axis=1)
y = data["target"]

X_train, X_test, y_train, y_test = \
    train_test_split(
        X, y,
        test_size=0.20,
        random_state=42
    )

model = RandomForestClassifier(
    n_estimators=200,
    random_state=42
)

model.fit(X_train, y_train)

print(
    "Accuracy:",
    model.score(X_test, y_test)
)

📐 Mathematics & Statistics

Machine Learning புரிந்துகொள்ள தேவையான முக்கிய mathematical concepts.

Σ

Mean

ஒரு dataset-ன் average value.

μ = (1/n) Σ xᵢ
Example

10, 20, 30 → Mean = 20

📊

Variance

Data points mean-இலிருந்து எவ்வளவு spread ஆகின்றன என்பதை அளக்கும்.

σ² = (1/n) Σ(xᵢ − μ)²
Example

Low variance → values close together. High variance → values widely spread.

📏

Standard Deviation

Variance-ன் square root.

σ = √Variance
Use

Feature scaling மற்றும் statistical analysis.

🎲

Bayes Theorem

ஒரு event-ன் conditional probability-ஐ calculate செய்யும்.

P(A|B) = P(B|A)P(A) / P(B)
Example

Spam email classification மற்றும் medical probability problems.

🔗

Correlation

இரண்டு variables இடையிலான linear relationship-ஐ அளக்கும்.

r = Cov(X,Y) / (σₓ σᵧ)
Range

−1 → negative correlation, 0 → no linear correlation, +1 → positive correlation.

🧪

Gradient

ஒரு function எந்த direction-ல் அதிகமாக மாறுகிறது என்பதை காட்டும்.

∇f(x) = [∂f/∂x₁, ..., ∂f/∂xₙ]
ML Use

Gradient Descent மூலம் model parameters update செய்யப்படுகிறது.

📚 Important ML Formulas

Interview மற்றும் practical ML projects-க்கு முக்கியமான formulas.

Mean Squared Error

MSE = (1/n) Σ(yᵢ − ŷᵢ)²
Use

Regression model prediction error.

Root Mean Squared Error

RMSE = √MSE
Use

Prediction error-ஐ original target unit-ல் புரிந்துகொள்ள உதவும்.

Log Loss

−1/n Σ[y log(p) + (1−y)log(1−p)]
Use

Binary classification probability predictions.

Precision

Precision = TP / (TP + FP)
Use

Predicted positive results-ல் உண்மையான positive proportion.

Recall

Recall = TP / (TP + FN)
Use

Actual positives-ல் கண்டறியப்பட்ட positive proportion.

F1 Score

F1 = 2 × Precision × Recall / (Precision + Recall)
Use

Precision மற்றும் Recall இரண்டையும் balance செய்யும் metric.

⚙️ Optimization Algorithms

Machine Learning மற்றும் Deep Learning models-ன் parameters-ஐ optimize செய்ய பயன்படும் முக்கிய algorithms.

1. Gradient Descent

Loss function-ஐ குறைக்கும் direction-ல் parameters-ஐ update செய்கிறது.

θₜ₊₁ = θₜ − α∇J(θₜ)
Example

α = learning rate. Gradient positive என்றால் parameter குறையும்; gradient negative என்றால் parameter அதிகரிக்கும்.

2. Batch Gradient Descent

θ ← θ − α(1/m)Σ∇Jᵢ(θ)
Idea

ஒவ்வொரு update-க்கும் முழு training dataset பயன்படுத்தப்படுகிறது.

3. Stochastic Gradient Descent

θ ← θ − α∇Jᵢ(θ)
Idea

ஒரு training example-ஐ வைத்து update செய்கிறது.

4. Mini-Batch Gradient Descent

θ ← θ − α(1/B)Σ∇Jᵢ(θ)
Idea

ஒரு small batch examples-ஐ பயன்படுத்துகிறது. Deep learning-ல் பொதுவாக பயன்படுத்தப்படும் approach.

5. Momentum

vₜ = βvₜ₋₁ + ∇J(θₜ)

θₜ₊₁ = θₜ − αvₜ
Idea

Previous gradients-ன் direction-ஐ நினைவில் வைத்துக் கொண்டு optimization-ஐ smooth செய்ய உதவுகிறது.

6. Nesterov Accelerated Gradient

vₜ = βvₜ₋₁ + ∇J(θₜ − αβvₜ₋₁)
Idea

Gradient-ஐ current position-க்கு பதிலாக look-ahead position-ல் evaluate செய்கிறது.

7. AdaGrad

Gₜ = Gₜ₋₁ + gₜ²

θₜ₊₁ = θₜ − α gₜ / (√Gₜ + ε)
Idea

ஒவ்வொரு parameter-க்கும் historical gradients அடிப்படையில் adaptive learning rate.

8. RMSProp

vₜ = βvₜ₋₁ + (1−β)gₜ²

θₜ₊₁ = θₜ − αgₜ/(√vₜ+ε)
Idea

Squared gradients-ன் exponential moving average பயன்படுத்துகிறது.

9. Adam

gₜ = ∇J(θₜ)

mₜ = β₁mₜ₋₁ + (1−β₁)gₜ

vₜ = β₂vₜ₋₁ + (1−β₂)gₜ²

m̂ₜ = mₜ/(1−β₁ᵗ)

v̂ₜ = vₜ/(1−β₂ᵗ)

θₜ₊₁ = θₜ − αm̂ₜ/(√v̂ₜ+ε)
Example

Neural network training-ல் widely used adaptive optimizer.

PYTHON — ADAM
import tensorflow as tf

optimizer = tf.keras.optimizers.Adam(
    learning_rate=0.001
)

model.compile(
    optimizer=optimizer,
    loss="categorical_crossentropy",
    metrics=["accuracy"]
)

10. AdamW

θₜ₊₁ = θₜ − α AdaptiveGradient − αλθₜ
Idea

Adam optimization-க்கு decoupled weight decay சேர்க்கப்படுகிறது.

11. AdaDelta

E[g²]ₜ = ρE[g²]ₜ₋₁ + (1−ρ)gₜ²
Idea

Learning rate-ஐ manually set செய்யும் dependency-ஐ குறைக்க வடிவமைக்கப்பட்டது.

12. Nadam

Nadam = Adam + Nesterov Momentum
Idea

Adam-ன் adaptive moments மற்றும் Nesterov momentum combination.

13. AMSGrad

v̂ₜ = max(v̂ₜ₋₁, vₜ)
Idea

Adam-ல் adaptive second moment estimate-ஐ non-decreasing ஆக maintain செய்கிறது.

14. Adamax

uₜ = max(β₂uₜ₋₁, |gₜ|)
Idea

Adam-ன் infinity-norm variant.

15. Newton's Method

θₜ₊₁ = θₜ − H⁻¹∇J(θₜ)
Idea

Gradient மட்டும் அல்லாமல் Hessian / second-order information-ஐ பயன்படுத்துகிறது.

16. L-BFGS

θₜ₊₁ = θₜ − αHₜ⁻¹gₜ
Idea

Full Hessian matrix-ஐ store செய்யாமல் அதன் approximation பயன்படுத்தும் quasi-Newton method.

17. Coordinate Descent

θⱼ ← argmin J(θ₁,...,θⱼ,...,θₙ)
Idea

ஒரே நேரத்தில் ஒரு parameter / coordinate-ஐ optimize செய்கிறது.

18. Proximal Gradient

θₜ₊₁ = proxαλR (θₜ − α∇f(θₜ))
Idea

Smooth மற்றும் non-smooth optimization problems-க்கு பயன்படும்.

19. Simulated Annealing

P(accept) = exp(−ΔE/T)
Idea

Local optimum-ல் சிக்காமல் global search செய்ய probability-based exploration பயன்படுத்துகிறது.

YOLO Core Formulas

IoU

IoU = Area(Prediction ∩ Ground Truth) / Area(Prediction ∪ Ground Truth)
Example

Predicted bounding box மற்றும் ground-truth bounding box overlap எவ்வளவு என்பதை அளக்கும்.

Precision

Precision = TP / (TP + FP)
Meaning

Model positive detection என்று கூறியவற்றில் எத்தனை உண்மையானவை?

Recall

Recall = TP / (TP + FN)
Meaning

Actual objects-ல் model எத்தனை கண்டுபிடித்தது?

F1 Score

F1 = 2PR/(P+R)
Meaning

Precision மற்றும் Recall இரண்டையும் ஒருங்கிணைக்கும் metric.

PROBLEM 01

❌ Small Objects

Image-ல் objects மிகவும் சிறியதாக இருந்தால் detection கடினமாகலாம்.

✅ Solution

Higher-resolution training data, representative examples, appropriate augmentation மற்றும் model/input configuration ஆகியவற்றை பரிசீலிக்கலாம்.

PROBLEM 02

❌ Poor Labels

Incorrect bounding boxes அல்லது wrong class labels model-ஐ பாதிக்கலாம்.

✅ Solution

Annotation review, label validation மற்றும் duplicate/noisy sample cleanup.

PROBLEM 03

❌ False Positives

Background objects target class என்று தவறாக detect செய்யப்படலாம்.

✅ Solution

Hard negative examples, threshold tuning மற்றும் dataset diversity.

PROBLEM 04

❌ False Negatives

Actual object இருந்தும் model detection செய்யாமல் விடலாம்.

✅ Solution

More representative data, annotation checking, suitable training configuration மற்றும் confidence/validation analysis.

PROBLEM 05

❌ Low FPS

Real-time video application-ல் inference speed போதுமானதாக இருக்காமல் இருக்கலாம்.

✅ Solution

Smaller model, suitable image size, hardware acceleration மற்றும் inference optimization.

PROBLEM 06

❌ Occlusion

ஒரு object மற்றொரு object-ஆல் மறைக்கப்படும்போது detection challenging ஆகலாம்.

✅ Solution

Occlusion examples, varied viewpoints மற்றும் realistic augmentation.
