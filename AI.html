🏠 Linear Regression — குமாரின் வீடு

சென்னையில் குமார் ஒரு வீட்டை வாங்க விரும்புகிறார். அவரிடம் பழைய வீடுகளின் area மற்றும் price data உள்ளது.

🎬 கதை

800 sq.ft வீடு ₹45 லட்சம். 1000 sq.ft வீடு ₹55 லட்சம். 1200 sq.ft வீடு ₹65 லட்சம். 1400 sq.ft வீடு ₹75 லட்சம்.

குமார் கேட்கிறார்: "1500 sq.ft வீடு சுமார் எவ்வளவு இருக்கும்?"

இதுதான் regression problem.

1

Data

Area + Price

2

Pattern

Area அதிகரிக்க price அதிகரிக்கிறது

3

Model

Linear Regression

4

Prediction

1500 sq.ft → price estimate

🧮 Formula

y = mx + b
  • x = Area
  • y = Price
  • m = slope
  • b = intercept

📊 Mini Dataset

Area Price
800 45 Lakh
1000 55 Lakh
1200 65 Lakh
1400 75 Lakh
Python • Scikit-learn Copy 

from sklearn.linear_model import LinearRegression

X = [
    [800],
    [1000],
    [1200],
    [1400]
]

y = [
    45,
    55,
    65,
    75
]

model = LinearRegression()

model.fit(X, y)

prediction = model.predict([[1500]])

print(prediction)

🎬 கதை

லதா bank-ல் loan கேட்கிறார். Bank-க்கு ஒரு முக்கியமான கேள்வி: "இந்த application approve செய்யலாமா?"

Income, credit score, age, existing loans போன்ற features அடிப்படையில் model Approved / Rejected probability கணிக்கிறது.

1

2

Calculation

Weighted sum

3

Sigmoid

0 முதல் 1 probability

4

🧮 Formula

P(y=1) = 1 / (1 + e-z)

Sigmoid function model output-ஐ 0 மற்றும் 1 இடையே probability ஆக மாற்றுகிறது.

🎯 Optimization

Gradient Descent — AI எப்படி தன் தவறை குறைக்கிறது?

🎬 கதை

ஒரு மாணவர் maths problem solve செய்கிறார். முதல் answer தவறாக இருக்கிறது.

அவர் error எவ்வளவு என்று பார்த்து, அடுத்த முயற்சியில் answer-ஐ சிறிது மாற்றுகிறார். மீண்டும் error பார்க்கிறார்.

பல iterations-க்கு பிறகு error குறைகிறது. இதுதான் Gradient Descent-ஐ புரிந்துகொள்ள ஒரு எளிய analogy.

θ = θ − α ∇J(θ)

இங்கே:

  • θ = model parameters
  • α = learning rate
  • J = loss function
  • ∇J = gradient
Python • Concept Copy 

weight = 0.0
learning_rate = 0.01

for step in range(1000):

    prediction = weight * x

    error = prediction - y

    gradient = 2 * x * error

    weight = weight - learning_rate * gradient

print(weight)

RAG — கல்லூரி PDF-ஐ படிக்கும் AI

🎬 கதை

"Unit 3-ல் Backpropagation என்றால் என்ன?"

LLM-க்கு முழு library-யையும் prompt-ல் அனுப்புவதற்குப் பதிலாக, documents-ஐ chunks-ஆக பிரித்து embeddings உருவாக்கலாம்.

Question வந்ததும் relevant chunks retrieve செய்து, அவற்றை context ஆக LLM-க்கு கொடுக்கலாம்.

1

2

3

4

Documents → Chunks → Embeddings → Vector Search → LLM
Python • RAG Concept Copy 

documents = load_documents()

chunks = split_into_chunks(
    documents
)

vectors = embed(chunks)

question = "Backpropagation என்றால் என்ன?"

relevant_chunks = search(
    vectors,
    question
)

context = "\n".join(
    relevant_chunks
)

answer = llm(
    context=context,
    question=question
)

print(answer)

Challenge Lab

🎯 AI Problem Solving Lab

Story-ஐ படித்த பிறகு நீங்களே problem solve செய்யுங்கள்.

BEGINNER

01. House Price

Area மற்றும் bedrooms மூலம் house price predict செய்யுங்கள்.

Regression problem. Linear Regression அல்லது Random Forest Regressor பயன்படுத்தலாம். MAE / RMSE evaluate செய்யலாம்.
BEGINNER

02. Spam SMS

SMS spam அல்லது normal என்று classify செய்யுங்கள்.

TF-IDF + Naive Bayes அல்லது Logistic Regression ஒரு நல்ல baseline.
INTERMEDIATE

03. Image Classifier

Vegetable images-ஐ category அடிப்படையில் classify செய்யுங்கள்.

CNN அல்லது transfer learning பயன்படுத்தலாம்.
INTERMEDIATE

04. Tamil Sentiment

Tamil customer review sentiment கண்டறியுங்கள்.

Text preprocessing → tokenizer / embeddings → classifier என்ற pipeline அமைக்கலாம்.
ADVANCED

05. PDF RAG

College PDF notes-ஐ வைத்து question answering assistant உருவாக்குங்கள்.

PDF → chunks → embeddings → vector search → context → LLM answer.
ADVANCED

06. AI Agent

Tools பயன்படுத்தும் AI agent உருவாக்குங்கள்.

Observe → Reason → Tool Call → Result → Next Action → Final Response.
Career Roadmap

🗺 Beginner → AI Engineer

இந்த roadmap-ஐ project-based learning உடன் follow செய்யுங்கள்.

01 — Python

Python basics, NumPy, Pandas, functions, classes, Git மற்றும் APIs.

02 — Mathematics

Statistics, probability, linear algebra, calculus மற்றும் optimization.

03 — Machine Learning

Regression, classification, clustering, feature engineering, evaluation.

04 — Deep Learning

Neural networks, CNN, RNN, LSTM, transformers.

05 — NLP & LLM

Tokenization, embeddings, attention, prompting, inference.

06 — RAG & Agents

Vector database, retrieval, tools, memory மற்றும் agent architecture.

07 — Production AI

API, deployment, monitoring, security மற்றும் evaluation.
